# Lenovo ThinkPad T14s Gen 4 (2024)

The Lenovo ThinkPad T14s Gen 4 (Intel) was originally announced in 2023, and this unit (`GM0FZDBC`) shipped from the factory in January 2024. I purchased this unit on the secondary market in November 2026 ([eBay #137465209524](https://www.ebay.com/itm/137465209524) for `$589.00 OBO + $21.90` shipping; see [2026 Laptop Buying Comparison — Round 2](../../2026-laptop-buying-round2.md)) to succeed [x1carbon2018](../x1carbon2018/x1carbon2018.md) as a 32 GB portable Linux workstation after [x1carbon23](../x1carbon23/x1carbon23.md) arrived with a dead battery and was returned.

## Usage

This laptop is used for coding, courseware development, travel, and running multi-VM RHEL `libvirt`/KVM and Podman container labs away from a desktop.

It shares the same 65W USB-C Power Delivery (`20V / 3.25A`) AC adapter used with `x1carbon2018`.

Because this laptop travels outside the home, keep a BIOS supervisor password, Secure Boot, and LUKS full-disk encryption enabled.

## Linux & Firmware Notes

- **Official Linux Certification**: Lenovo's [Linux for Personal Systems](https://www.lenovo.com/linux) page (`PD031426`) lists the ThinkPad T14s Gen 4 (`21F6`, `21F7`) as certified for Ubuntu 22.04, Red Hat Enterprise Linux 9.2, and Fedora 38+. Hardware power profiles (`Fn+L` Power Saver, `Fn+M` Balanced, `Fn+H` Performance) work through `thinkpad_acpi` and `power-profiles-daemon` / `tuned-ppd`.
- **Mainline Kernel Drivers**: CPU frequency scaling (`intel_pstate`), Iris Xe graphics (`i915` / `xe`), wireless (`iwlwifi` / `btintel`), Sound Open Firmware audio (`sof-audio-pci-intel-tgl`), the 5MP RGB+IR USB webcam (`uvcvideo`, avoiding the Intel MIPI IPU6 camera option), and `s2idle` (S0ix) standby all use mainline kernel drivers, with no out-of-tree kernel modules needed on `bootc`.
- **WWAN Cellular Modem (`Fibocom L860-GL-16`)**: The factory-installed Intel XMM7560-based PCIe LTE modem (`5W10V25828`) uses the mainline `iosm` kernel driver and `ModemManager` (requiring an FCC unlock procedure in `ModemManager` if cellular data is used). When not using a cellular SIM card, disable Wireless WAN in BIOS (`Security -> I/O Port Access -> Wireless WAN -> Disabled`) so the PCIe modem consumes `0W` in idle/standby and does not generate `ModemManager` / `iosm` log noise.
- **Userspace Components**: The Match-on-Chip fingerprint reader (`5F30V25938`) uses `fprintd` / `libfprint`. Mesa provides OpenGL (`iris`) and Vulkan (`anv`). `intel_lpmd` is an optional low-power daemon, not a kernel driver.
- **Hardware Video Decode**: Check which VA-API profiles the stock Fedora driver provides with `vainfo`. Codecs missing from the stock driver require `intel-media-driver` from RPM Fusion (see `Q14` in [immutable/migration/README.md](../../../immutable/migration/README.md#open-questions)).
- **Firmware Updates (`fwupd` / LVFS)**: System UEFI/BIOS, Embedded Controller (EC), Intel Management Engine, and NVMe SSD firmware updates are delivered through LVFS.

  ```sh
  fwupdmgr refresh
  fwupdmgr get-updates
  fwupdmgr update
  ```
